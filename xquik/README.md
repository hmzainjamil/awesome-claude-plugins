# Xquik

Use Xquik from Claude Code for X data workflows that need search, monitoring,
exports, webhooks, or MCP tools.

## Resources

- [API documentation](https://docs.xquik.com/api-reference/overview)
- [MCP documentation](https://docs.xquik.com/mcp/overview)
- [Source repository](https://github.com/Xquik-dev/x-twitter-scraper)

## Install

```bash
/plugin install xquik@awesome-claude-plugins
```
